BEHIND THE WEBSITE

A small project with
a clear purpose.

StudyFlow is an educational demonstration of how HTML, CSS and JavaScript work together to create a usable, interactive website.

01 / STRUCTURE

HTML

Semantic elements such as header, nav, main, section, form and footer organise the content and give it meaning.

02 / DESIGN

CSS

Reusable styles control colours, spacing, typography, card layouts, responsive grids and accessible visual states across three pages.

03 / INTERACTION

JavaScript

Event listeners power adding, completing, deleting, searching and filtering tasks. Browser storage remembers tasks and theme preferences.

PROJECT ORGANISATION

An easy-to-follow structure

The website separates content, presentation and behaviour into distinct files and folders, as required for a typical web development laboratory.

index.htmlMain dashboard with task form, progress panel and task list.
pages/Additional HTML pages: this introduction and a user guide.
css/Central stylesheet with responsive layout and colour themes.
js/Task management and shared interactions, including a FAQ accordion.
images/Original SVG logo and study desk illustration.
